## Reporting a vulnerability / Como reportar uma vulnerabilidade

Please **do not** open a public GitHub issue for security vulnerabilities.

Por favor, **não** abra uma issue pública no GitHub para vulnerabilidades de segurança.

### Contact / Contato

- **Email:** [punkcodesolution@gmail.com](mailto:punkcodesolution@gmail.com)
- **Organization:** [Punk-Code-Solution](https://github.com/Punk-Code-Solution) on GitHub

Include as much detail as you can: description, steps to reproduce, affected
URLs or components, and (if available) a proof of concept.

Inclua o máximo de detalhes possível: descrição, passos para reproduzir, URLs
ou componentes afetados e (se houver) uma prova de conceito.

### What to expect / O que esperar

- We aim to acknowledge reports within **5 business days**.
- Procuramos confirmar o recebimento em até **5 dias úteis**.
- If the report is accepted, we will work on a fix and coordinate disclosure.
- Se o relatório for aceito, trabalharemos em uma correção e alinharemos a divulgação.
- If declined, we will explain why (e.g. not reproducible, out of scope, or
  already known).
- Se for recusado, explicaremos o motivo (ex.: não reproduzível, fora do escopo
  ou já conhecido).

Thank you for helping keep Punk Code Solution and our users safe.

Obrigado por ajudar a manter a Punk Code Solution e nossos usuários seguros.
